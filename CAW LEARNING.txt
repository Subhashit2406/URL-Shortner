Interview Questions (Very Important)
Q1. Why use a Monorepo?

Answer:
To organize multiple services (API, workers, shared libraries) in a single repository while sharing code and allowing independent deployment and scaling.

Q2. Why store configuration in .env?

Answer:
To separate environment-specific configuration from application code, improving security, portability, and deployment flexibility.

Q3. What is Fail-Fast?

Answer:
Fail-Fast is the practice of validating configuration and dependencies during startup so the application crashes immediately instead of failing unpredictably at runtime.

Q4. Why use Pydantic Settings?

Answer:
It provides type-safe configuration management by automatically loading, validating, and converting environment variables.

Q5. Why create /health?

Answer:
To allow load balancers, orchestrators, and monitoring systems to verify that the service is running correctly.

Q6. Why validate the PORT?

Answer:
To prevent invalid network configuration from causing runtime failures.

Q7. Why use requirements.txt?

Answer:
To lock dependency versions and ensure reproducible environments across local development, CI/CD, and production.

Q8. Why use a virtual environment?

Answer:
To isolate project dependencies and prevent version conflicts with other Python projects.
